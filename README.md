An end-to-end Machine Learning web application designed for engineering students, training and placement officers (TPOs), and academic advisors to diagnose campus recruitment readiness, predict placement likelihood, identify domain skill gaps, and provide personalized improvement roadmaps.

---

## 1. Project Overview

During campus placements, students often face rejection not due to a lack of talent, but because they are unaware of their individual weaknesses across academic thresholds, technical problem-solving, behavioral communication, or project portfolios.

**PathFinder AI** solves this problem by combining:
1. A **Random Forest Machine Learning Classifier** trained on engineering recruitment patterns to estimate statistical placement likelihood.
2. A **0–100 Placement Readiness Index** that provides a deterministic, multi-pillar evaluation (Academics, Aptitude, Technical Skills, Communication, and Practical Experience) while strictly distinguishing algorithmic probability from holistic readiness.
3. A **Domain Skill Gap Analyzer** that contrasts student competencies against high-demand IT roles (Software Developer, Data Analyst, ML Engineer, Cloud/DevOps, Cybersecurity) and prescribes customized project ideas and interview strategies.
4. An **Interactive Analytics Dashboard & SQLite Repository** to log, search, and visualize student cohorts over time.

---

## 2. Key Features

- **Holistic Profile Assessment**: Evaluates CGPA, aptitude score, technical rating, communication rating, internships, projects, active backlogs, programming skills, and preferred career domain.
- **Genuine Machine Learning Pipeline**: Scikit-learn Random Forest Classifier pipeline with `StandardScaler` preprocessing, 80/20 stratified split, and verified test-set metrics (95.0% accuracy, 97.0% F1-score).
- **Two Distinct Evaluation Metrics**:
  - **ML Placement Likelihood (%)**: Probability estimate generated by an ensemble of decision trees.
  - **Readiness Score (0–100)**: Interpretable composite index combining five foundational preparation pillars.
- **Pillar-by-Pillar Qualitative Feedback**: Automated diagnostic assessment across Academic Standing, Technical Capabilities, Communication Articulation, and Practical Exposure.
- **Interactive Competency Spider Radar**: Dynamic Chart.js radar visualization comparing candidate strengths across all five dimensions.
- **Career Domain Guidance Engine**: Tailored roadmaps (Foundational, Intermediate, Advanced), capstone project ideas, and high-yield interview questions for 5 IT disciplines:
  - Software Development Engineer (SDE / Full Stack)
  - Data Analyst / Business Intelligence Engineer
  - Machine Learning Engineer / AI Developer
  - Cloud Platform & DevOps Engineer
  - Cybersecurity Analyst
- **Cohort Analytics Dashboard**: 5 live visualizations based on actual SQLite database records:
  - Category breakdown (High, Moderate, At Risk)
  - Academic CGPA tier distribution
  - Technical vs. Communication scatter correlation
  - CGPA vs. Placement probability scatter
  - Active backlogs penalty impact chart
- **Persistent SQLite Database**: Parameterized CRUD operations, instant search, and confirmation-based deletion.
- **Strict Server & Client Validation**: Guards against invalid scores, negative inputs, and boundary overflow.
- **Fully Local & Free**: Requires zero paid third-party APIs, external tokens, or cloud subscriptions.

## 7. Machine Learning Methodology & Evaluation

The predictive engine uses a supervised ensemble learning pipeline:

1. **Preprocessing**: Numerical features are scaled using `StandardScaler` to normalize variance without introducing train-to-test leakage.
2. **Model**: `RandomForestClassifier` with:
   - `n_estimators = 120`
   - `max_depth = 8`
   - `min_samples_split = 4`
   - `class_weight = "balanced"`
3. **Validation**: Evaluated on a 20% stratified test set (300 unseen student profiles).

### Actual Test Evaluation Metrics

| Metric | Score | Explanation |
| :--- | :--- | :--- |
| **Accuracy** | **95.00%** | Fraction of correct classifications on held-out test data |
| **Precision** | **98.00%** | Ratio of true positive placement predictions to all positive predictions |
| **Recall** | **96.08%** | Ratio of placed candidates correctly identified by the classifier |
| **F1-Score** | **97.03%** | Harmonic mean of precision and recall |
| **ROC-AUC** | **99.09%** | Area under the Receiver Operating Characteristic curve |

### Feature Importances (Gini Impurity Reduction)

1. **Active Backlogs**: 47.7% (Single strongest campus recruitment cutoff factor)
2. **CGPA**: 21.7% (Academic qualification eligibility threshold)
3. **Aptitude Score**: 12.3% (Initial screening round clearance driver)
4. **Technical Score**: 9.3% (Coding fluency and technical interview indicator)
5. **Communication Score**: 4.7% (HR and managerial interview performance)
6. **Projects & Internships**: 4.4% (Resume screening and hands-on validation)

## 10. College Mini-Project Viva Reference & Defense

When presenting this project to external examiners or professors, be prepared to answer:

1. **Q: Why use Random Forest instead of Logistic Regression?**
   - *A:* Placement eligibility criteria feature sharp non-linear thresholds (e.g., active backlogs disqualify candidates even with a 9.5 CGPA). Decision tree ensembles capture these non-linear step-functions and feature interactions without requiring complex polynomial transformations.
2. **Q: How is Data Leakage prevented?**
   - *A:* The `StandardScaler` is wrapped inside a scikit-learn `Pipeline`. Parameters ($\mu$ and $\sigma$) are computed strictly on the training partition (`X_train`) and applied downstream to the test set and live inference requests.
3. **Q: Why separate Placement Likelihood from the Readiness Score?**
   - *A:* Placement likelihood is an algorithmic statistical probability (ratio of trees predicting placement). To avoid giving students a misleading sense of finality, an independent 0–100 Placement Readiness Score provides holistic, constructive feedback across all five pillars.

## 12. Limitations & Future Scope

### Current Limitations
- Synthetic demonstration dataset: Modeled after real-world placement criteria, but real placement rates fluctuate with macroeconomic IT hiring cycles.
- Single-institution criteria: Cutoffs vary between Tier-1 product corporations and mass recruitment IT service firms.

### Future Enhancements
- Resume parsing using Natural Language Processing (spaCy / PyPDF2) to auto-extract skills and projects.
- Company-specific cutoff profiles (e.g. Google vs. TCS vs. Infosys eligibility rules).
- Email notifications sent to training and placement officers for at-risk candidates.
